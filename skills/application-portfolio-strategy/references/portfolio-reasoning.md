# 现实难度与投递组合

对每个重点候选岗位记录四类判断：岗位价值与偏好、硬资格与地点、现实竞争位置、加入组合后新增的机会。追问真实候选池、最可能的淘汰环节、机构和招聘人数的影响，并区分招聘事实与竞争判断。

申请银行、保险、证券等大型企业时，结合本科院校、最高学历、专业和实习结构评估现实初筛位置。总部岗位默认属于“抽奖机会”，涵盖总部业务和销售岗位；少量高价值机会可进入组合。省级分支管培与后台岗位默认冲刺，同机构层级中管培通常更难。分支销售与客户开发岗位的院校筛选通常更宽，可提供相对现实的入口；结合招聘规模、城市、销售考核和培养质量选择。整体仍按大型企业校招的较高竞争强度看待。岗位级证据可以调整默认档次，结论用相对难度表达。

用简短矩阵比较硬资格、本科初筛、相关实习、专业测评、笔面表现、销售适应和地点安排。多个总部或省级后台岗位可能共享本科初筛风险；销售岗位若工作可接受，能增加不同的筛选路径。替换比较回答“换岗后增加什么机会、放弃什么价值”。

销售、客户和业务岗位按工作实际区分个人获客与业绩考核、混合服务、客户支持等类型。现实难度与职业偏好分别记录，说明岗位的发展价值、技能积累和工作代价。若候选人接受多个合适的销售岗位进入正式组合，每个岗位都说明它能增加哪条上岸路径，以及与其他销售岗的失败风险是否重合。个人喜好在整体上岸机会之后权衡。“保底”表示组合中的相对定位。
