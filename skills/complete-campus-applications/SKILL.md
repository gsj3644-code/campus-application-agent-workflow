# 校招网申填写与投递

## 模式与资料

区分岗位评估、字段指导、开放题、整页检查、浏览器填写和最终投递。岗位评估交给 `find-non-sales-campus-jobs`；需要补充个人事实时调用 `build-candidate-profile-and-resume`。

以 `个人求职事实信息库.md` 为事实来源，先读“快速读取区”，再读取岗位交接记录、定向简历和网页字段。页面要求联系方式、证件号码、出生日期、住址、家庭成员等字段时，在当前任务的授权范围内读取事实库专门章节；库中缺失时，可从用户明确授权的材料中提取并回写。摘要不足时读取事实库详细章节、简历库和证明材料。用户只要一段文字时，直接交付一个成熟版本。

## 执行

1. 记录字段原名、作用域、类型、必填状态、语言和字符限制。
2. 从已确认事实中选材，区分教育、实习、课程项目、校园经历、奖项、技能和兴趣。
3. 开放题覆盖明示维度；关键缺口集中追问一至三个问题。
4. 通用档案字段保持跨岗位适用，岗位独立字段按 JD 定向。
5. 提交前核对数字、日期、名称、项目性质、个人分工、材料版本和重复项。
6. 按授权完成填写、保存或提交，并记录页面最终状态和后续安排。

获得用户明确确认或可靠材料后，可直接修正事实库的当前值、快速摘要和更正记录。写作与事实处理读取 [application-writing-and-truth.md](references/application-writing-and-truth.md)；浏览器操作读取 [browser-safety.md](references/browser-safety.md)。

## 核心边界

使用可追溯事实，准确呈现课程属性和团队个人分工。未经用户提供或授权的敏感值不得推测、补造或从无关来源搜集；面向聊天汇报时默认遮蔽完整证件号和非必要联系方式，但在用户授权的申请页面中填写完整值。页面要求候选人独立作答时，提供事实要点与思路，由用户完成最终表达。最终提交及撤回、删除等难恢复操作仍采用单独授权；“不投递”是提交动作的停止指令。

## 输出

字段结果包含建议内容、字符数、事实来源和待补信息；开放题默认提供一个可直接使用的版本；浏览器任务报告已填写、已保存、待处理项和页面状态，并将投递结果回流总规划。
