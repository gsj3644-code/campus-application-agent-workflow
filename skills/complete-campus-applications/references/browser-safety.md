# 浏览器填写授权

## 授权层级

按查看、填写、保存、上传、最终提交逐级执行。最终提交、确认投递、撤回、删除和注销采用单独授权；用户说“不投递”时停在提交前。登录、验证码和技术故障保留已准备内容并报告当前页面状态。

用户已授权在具体网申填写任务中，直接读取并填写其本人明确提供、确认或授权从材料提取的联系方式、证件号码、出生日期、住址、家庭成员等敏感求职字段。填写动作无需仅因字段敏感再次确认；该授权不包含最终提交、撤回、删除或注销。

## 操作

1. 按浏览器控制 Skill 启动会话并读取页面。
2. 记录岗位、页面、账号范围和当前授权层级。
3. 识别字段作用域，共享档案保持跨岗位适用。
4. 填写后复读页面，核对字段值、分类、日期和保存状态。
5. 汇报已填写、已保存、待处理项、原因和页面最终状态。
