# 网申写作与事实

## 选材

拆解题目的名称、时间、角色、行动、工具、成果、投入、付费、动机和反思等明示维度。从实习、课程项目、学生工作、志愿服务、兴趣、游戏、工具使用、学习习惯、个人动机与工作方式中选择已确认素材。关键缺口集中追问一至三个问题，其余内容采用准确的阶段或范围表达。

## 表达

以具体事实、行动和工作习惯为主，使用自然、简洁、有信息量的中文。通过选材体现岗位相关性，控制模板句、抽象能力词和业务黑话。团队经历写清个人角色，正式答案聚焦候选人实际完成的内容。单段请求默认交付一个成熟版本；明显不同的回答策略才提供备选。

用户要求自然化时调用 `humanizer-zh` 复核，保持事实与原有语气。

## 事实状态

- 已确认：可用于正式填写。
- 待核验：保留来源和影响字段。
- 文案方案：作为表达建议，与事实分开。
- 敏感求职字段：本人明确提供、确认或授权从材料提取后，保存完整当前值及来源、日期和使用边界；可用于授权的网申填写，不进入公开简历或无关输出。

数字、日期、名称或项目性质出现多版本时，按建库 Skill 的 [fact-database-schema.md](../../build-candidate-profile-and-resume/references/fact-database-schema.md) 处理。新确认写回事实库；旧值保留为已作废；文案概括保持文案属性。

## 成稿验收

检查题目维度覆盖、事实依据、个人角色、岗位相关性、自然表达、用户语气偏好和字符限制。
