# 单一事实库结构

将 `个人求职事实信息库.md` 作为唯一事实来源。事实在这里维护；建档进度、简历母版、岗位表和网申答案属于状态或派生结果。

## 快速读取区

在文件顶部保留固定的 `## 快速读取区`，只记录当前有效的高频字段：

- 最近更新时间；
- 招聘类型、届别及预计毕业/学位授予时间；
- 学历、专业和学校背景摘要；
- 经历与已确认技能摘要；
- 目标城市和岗位方向及优先级；
- 明确拒绝的职责；
- 加班、倒班、轮岗、驻点、工厂和异地分配边界；
- 行业、公司规模、薪资偏好；
- 实习/正式岗接受范围；
- 网申常用教育、经历、证书和语言标准写法；
- 当前关键缺口和未解决冲突。

快速区是同一文件内的索引。修改详细章节中的当前事实时，同时刷新对应摘要；详细记录保留完整上下文。

## 详细章节

按需包含：基本信息、网申敏感字段、教育背景、实习与工作、项目、校园与志愿、奖项与证书、技能与语言、兴趣与工作方式、求职偏好、材料索引、待核验事项、冲突记录、事实更正记录。

## 网申敏感字段

用户已授权保存其本人明确提供、明确确认或授权从求职材料中提取的联系方式、证件号码、出生日期、住址、家庭成员及其他网申所需敏感字段。每项记录当前值、状态、来源或材料定位、确认/提取日期和使用边界。不得仅因敏感而拒绝保存，也不得推测缺失值或从无关来源扩展搜集。

该章节不进入快速读取区、公开简历、岗位搜索结果或无关输出。仅在具体网申、证明、背景核验等用户授权的求职任务中按字段读取；展示或汇报时默认遮蔽完整证件号和非必要联系方式，但向用户授权的申请页面填写时使用完整值。

每项事实可记录当前值、状态、来源、确认日期、使用边界和材料定位。状态使用：已确认、待核验、已作废；文案建议保持“文案方案”状态。

## 冲突与更正

同一字段存在多个版本时，在冲突记录中保存各版本和来源。用户最新明确确认或可靠材料支持新值后：

1. 更新该字段的当前值；
2. 将旧值标记已作废；
3. 在事实更正记录写入日期、执行 Skill、旧值、新值、依据和复核结果；
4. 刷新快速读取区对应摘要；
5. 重新读取修改段落确认结果。

## 下游读取

规划和搜索先读快速读取区。网申在识别页面字段后读取对应详细章节；敏感字段可直接从事实库专门章节或用户授权的材料中读取并填写。摘要不足、存在冲突或需要证据时，再按需扫描简历库和证明材料。
