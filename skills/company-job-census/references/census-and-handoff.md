# Job Census 与交接

底表的主键优先为“公司＋招聘项目＋Job ID”；若 ID 在机构间复用，加入机构；无 ID 用官方详情 URL，再退化为“项目＋机构＋岗位名＋地点”，并标记主键不稳。每条记录保留原始来源和核验时间。字段可随 JD 增减，至少让第二阶段能够回到官方事实。

| 字段组 | 记录内容 |
| --- | --- |
| 身份 | 公司、招聘项目、岗位名、Job ID、机构／部门、官方链接、状态、采集时间 |
| 供给 | 城市／多地点、岗位类别、岗位级 HC、截止日期 |
| JD | 职责、学历、专业、技能、证书、其他任职要求 |
| 事实标签 | 销售／获客、编程、建模、分公司、轮岗、异地、证书等；值为明确有／明确无／未披露 |
| 证据 | 对关键字段的官方短摘录或页面位置、来源 URL、必要的冲突记录 |
| 缺口 | 未披露、无法访问、语义歧义、日期过期等及其影响范围 |

Excel 主表每岗一行，设置筛选和冻结表头；职责与任职要求保留完整原文，可放在同一行的长文本列或按 Job ID 对应的详情工作表。将招聘规则、覆盖记录和信息缺口放在底表的简短说明工作表或随附文件中。核对总行数、唯一编号及链接；完整底表供第二阶段原样引用。

交接提示建议写成：

> 请用 `$application-portfolio-strategy` 帮我制定这家公司的投递方案。完整 Excel 岗位底表和招聘规则在 [绝对路径]，我的经历与偏好在 [绝对路径]。[本次特殊要求，如有。]

提示中的路径和背景按实际产物填写，不在 Skill 中写死。若跨对话不能访问该文件，直接把完整底表作为附件带入新对话。
