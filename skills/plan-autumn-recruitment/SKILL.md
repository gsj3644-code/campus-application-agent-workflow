# 秋招总规划

## 读取

以 `个人求职事实信息库.md` 为事实来源，先读“快速读取区”，并读取 `求职建档进度.md`、最新岗位、投递和笔面试结果。摘要不足时读取相关详细章节和材料。

## 规划

1. 判断当前阶段：建档、岗位发现、材料定制、网申、笔面试或复盘。
2. 汇总目标、限制、现有材料、近期截止、阻塞和最新结果。
3. 按岗位匹配、竞争强度、截止时间、申请成本和面试概率，选择最能推进结果的 1 至 3 项行动。
4. 给出今天、本周和近期节奏，标明负责人 Skill 与完成标准。
5. 接收新岗位、投递、测评和面试结果，更新优先级与下一步。

资料缺口作为并行补充任务；已确认信息足以支持行动时直接推进。主投和可以投优先，冲刺保留合理比例，不建议投等待用户决定。

## 路由

- 资料、偏好与简历：`build-candidate-profile-and-resume`
- 岗位搜索、核验与比较：`find-non-sales-campus-jobs`
- 字段、开放题、页面填写与投递：`complete-campus-applications`

综合流程：`事实 → 岗位核验 → 定向简历 → 网申 → 结果回流`。

## 输出

先给最高优先级动作和理由，再给行动清单。每项包含时间、任务、所需材料、完成标准、阻塞项和下一 Skill；已完成事项进入结果记录。
